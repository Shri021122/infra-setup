# Scaling Procedures

## Adding Worker Nodes

**No cluster disruption. Zero-downtime operation.**

### 1. Update Terraform variables

```hcl
# terraform/proxmox/terraform.tfvars

worker_count = 3   # was 2

worker_ip_addresses = [
  "192.168.10.111",
  "192.168.10.112",
  "192.168.10.113",   # <── new node
]
```

### 2. Apply infrastructure changes

```bash
cd terraform/proxmox
terraform plan -out=scale-workers.tfplan
terraform apply scale-workers.tfplan
```

Terraform creates only the new VM (existing VMs are unchanged — `count` lifecycle).

### 3. Install RKE2 agent on new node

```bash
# The install script reads from inventory.ini (regenerated by Terraform)
./rke2/scripts/install-worker.sh
# Script is idempotent — skips already-installed nodes
```

### 4. Verify

```bash
kubectl --kubeconfig .secrets/kubeconfig-admin.yaml get nodes -o wide
# New node should appear as Ready within 3-5 minutes
```

## Scaling Worker Resources (CPU/RAM)

**Requires node drain — zero-downtime with multiple workers.**

```bash
# Step 1: Drain the node (reschedules pods)
kubectl drain rke2-worker-3 --ignore-daemonsets --delete-emptydir-data --timeout=5m

# Step 2: Update resources in terraform.tfvars
#   worker_cpu_cores  = 12  (was 8)
#   worker_memory_mb  = 32768  (was 16384)

# Step 3: Apply Terraform (will update VM but node is drained)
cd terraform/proxmox
terraform apply -target='module.worker_nodes[2]'

# Step 4: Proxmox reboots VM with new resources
# Step 5: Uncordon after reboot completes
kubectl uncordon rke2-worker-3
```

## Adding Master Nodes

**etcd quorum requires odd numbers. Go from 3 → 5, never 3 → 4.**

> **Warning:** Adding master nodes requires careful etcd membership management.

```bash
# Step 1: Update Terraform
#   master_count = 5
#   master_ip_addresses = [...add 2 more IPs...]

# Step 2: Apply (creates 2 new master VMs)
terraform apply -target='module.master_nodes[3]' -target='module.master_nodes[4]'

# Step 3: Install RKE2 server on new masters
# The install script detects is_init_node=false and joins existing cluster
./rke2/scripts/install-master.sh

# Step 4: Verify etcd membership
kubectl --kubeconfig .secrets/kubeconfig-admin.yaml \
  -n kube-system exec -it etcd-rke2-master-1 -- \
  etcdctl --cacert /var/lib/rancher/rke2/server/tls/etcd/server-ca.crt \
          --cert   /var/lib/rancher/rke2/server/tls/etcd/client.crt \
          --key    /var/lib/rancher/rke2/server/tls/etcd/client.key \
  member list
```

## Scaling Disk Storage

**Online expansion supported with CSI drivers. No pod restart needed.**

```bash
# Edit PVC directly (if StorageClass has allowVolumeExpansion: true)
kubectl patch pvc prometheus-prometheus-kube-prometheus-stack-prometheus-db-0 \
  -n monitoring \
  -p '{"spec":{"resources":{"requests":{"storage":"100Gi"}}}}'

# OR update Terraform variable and apply:
#   prometheus_storage_size = "100Gi"
terraform apply -target='module.prometheus_stack'
```

## Removing Worker Nodes

```bash
# Step 1: Drain
kubectl drain rke2-worker-2 --ignore-daemonsets --delete-emptydir-data

# Step 2: Delete from cluster
kubectl delete node rke2-worker-2

# Step 3: Update Terraform and apply (destroys VM)
#   worker_count = 1
#   Remove IP from worker_ip_addresses
terraform apply
```

## Resource Adjustment Quick Reference

| Change | Terraform Target | Disruption |
|--------|-----------------|------------|
| Add worker | `module.worker_nodes[N]` | None |
| Worker CPU/RAM | `module.worker_nodes[N]` | Node drain required |
| Add masters (3→5) | `module.master_nodes[3]`, `[4]` | None (etcd leader election) |
| Master CPU/RAM | Drain master, apply, uncordon | Rolling |
| Expand PVC | Edit PVC directly | None (online resize) |
| Expand VM disk | Resize in Proxmox + OS | Reboot required |

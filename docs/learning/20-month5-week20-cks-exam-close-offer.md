# Month 5, Week 20 — Take CKS + close the offer

> The final week. You sit CKS. You close on the best offer. You sign.
> You're done.

## Goal for the week

By Sunday:
- CKS exam taken and passed
- Best offer accepted and signed
- LinkedIn updated with new role + 2 certs
- Plan for the next 90 days at the new job

## Time breakdown

- CKS exam: ~3 hours (exam + buffer)
- Offer negotiation + signing: ~3 hours
- LinkedIn update + post: ~1 hour
- New-job planning: ~2 hours
- Recovery / celebration: as much as you want

---

## Part 1 — CKS exam day

Same routine as CKA Week 18:
- ≥8 hours sleep night before
- Clean desk, no devices
- Light meal 1 hour prior
- Aliases set at start of exam
- Verify after every task
- Skip + return for hard tasks

CKS-specific:
- Bookmark falco.org, trivy.dev in your exam browser before starting
- The Falco rule writing tasks are recipe-based — practice them cold
- For Trivy / kube-bench tasks: read the output carefully, fix the
  specific check that fails

If you pass: 2-line LinkedIn post. "Just passed CKS, completing my CKA+CKS
journey from the last 30 days. Thanks to <community/mentors> for the help."

If you fail: take 1 week off cert prep. Retake in 2-3 weeks. Doesn't
derail the offer.

## Part 2 — Close the offer

You should have 1-2 offers in hand by now. If not, that's covered in
Part 3 fallback.

### 2.1 Compare offers if multiple

Build a side-by-side:

| Component | Offer A | Offer B |
|---|---|---|
| Base salary | | |
| Joining bonus | | |
| ESOP/RSU value (estimated cash) | | |
| Annual bonus target | | |
| **Total Year 1** | | |
| **Total Year 4 (with vesting)** | | |
| Role + scope | | |
| Manager quality (subjective 1-10) | | |
| Team / tech stack interest (1-10) | | |
| WFH / location | | |
| Stability (1-10) | | |
| Growth potential (1-10) | | |

DON'T just pick by money. A 60 LPA offer at a company with a great
manager + interesting tech beats a 70 LPA offer at a meeting-heavy place
with no autonomy.

### 2.2 Negotiate final terms

You have leverage. The company has invested 4-6 weeks. Backing out now
costs them. Use this carefully:
- One final ask: usually a joining bonus or an extra equity grant
- Frame as "I want to sign today; can we look at X to make this work?"
- Accept their first or second response. Don't haggle indefinitely.

### 2.3 Sign

Get the offer in writing (PDF). Check:
- Exact title
- Reporting manager name
- Start date
- All comp components, with vesting schedules if ESOP/RSU
- Notice period (theirs to you, yours to them)
- Non-compete / non-solicit terms (read carefully; push back if scope is wide)
- IP assignment (standard, but read the language)

Sign + return.

### 2.4 Resign from current role

After signing the offer:
- Resign professionally in writing
- 1-month notice (or per your contract)
- Don't badmouth in the exit interview
- Hand over your work properly — leave reputation intact

## Part 3 — If you don't have an offer yet

A small but real chance: you reach Week 20 without an offer signed. Causes:
- Long company processes (some take 8-10 weeks)
- Bad luck with hiring freezes mid-process
- A weak spot you didn't realize until interviews

Plan:
- Don't panic. The 4 months of prep don't evaporate.
- Continue interviewing while you study CKS
- Once CKS is done, you have BOTH certs as a recruiter magnet
- Spend Week 21+ as Month 4 redux: aggressive applications, system design
  reps, target Tier 2 if Tier 1 isn't biting
- Realistic outcome: signed offer by Week 24 (~6 weeks late)

Don't blame yourself; this is variance, not a verdict.

## Part 5 — Plan the first 90 days at the new job

You don't want to walk in on Day 1 unprepared. Spend 1-2 hours mapping:

### Week 1
- Meet everyone on the team (1:1s)
- Read all internal docs / runbooks
- Set up dev environment
- Don't propose changes yet

### Weeks 2-4
- Pick a small project to ship (small, scope-bounded, high-confidence)
- Build relationships outside the immediate team
- Understand on-call rhythm
- Map the codebase / clusters

### Weeks 5-12
- Ship a meaningful project
- Form opinions on what's broken
- Propose 1-2 improvements (cautiously, after building credibility)

The classic mistake new hires make: come in hot, propose 10 changes Day 1,
alienate the team. Don't.

## What's next

Nothing. You're done with the curriculum. You have a new role.

But the learning doesn't stop:
- 1 conference per year
- 1 open-source contribution per quarter (your operator counts)
- 1 blog post per quarter
- 1 mock interview every 6 months (stay sharp for future opportunities)

You're now in the long game. The senior K8s/Platform engineer career
unfolds over 10+ years. The next milestone is "Staff" or "Principal,"
worth 80-150 LPA at the same companies. Same playbook, different scale.
